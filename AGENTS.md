# Samarbeid i Oslo Sprint

- Les README.md, TASKS.md og docs/api.md før du tar en oppgave.
- Start fra det delte grunnlaget på `main`. Bruk oppgavens branch fra TASKS.md og hold endringer innenfor avtalt filområde.
- Lever via en pull request fra oppgavebranchen til `main`. Beskriv hva som er endret, hvordan du testet og hva som gjenstår. Rajvir følger opp integrasjonen og rekkefølgen i TASKS.md.
- Avklar endringer i API-formatet med frontend og integrasjonsansvarlig. Oppdater eksempelsvar og typer sammen med formatet.
- Bruk eksempelmodus som standard. Del `backend/.env.example` med tomt nøkkelfelt. Rajvir legger selv inn API-nøkkelen lokalt i `backend/.env` eller i backend-prosessens miljø, og bruker live-modus når modelltilkoblingen er klar. Hold nøkkelen og ekte kontrakter utenfor Git, frontend og logger.
